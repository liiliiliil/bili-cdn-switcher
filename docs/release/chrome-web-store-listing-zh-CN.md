# Chrome Web Store 商店文案（简体中文）

## 名称

`Bili CDN Switcher - B站视频 CDN 优选器`

## 简短说明

`为 B 站点播视频在本机测速并切换 bilivideo.com CDN；无需全局代理，不上传数据。`

## 详细说明

看 B 站时，如果宽带测速正常，视频却总在转圈，问题有时出在当前分配的媒体 CDN 或跨境路由上。

Bili CDN Switcher 只做一件事：在 B 站点播页里观察当前 `bilivideo.com` 媒体请求，用这段视频的有效地址做一轮有上限的本地测速，再把后续请求切到更合适的 host。

主要功能：

- 自动记录当前视频实际使用的 CDN host；
- 优先测试 B 站为当前视频签发的原始地址；
- 最多初筛 8 个候选，再对最快的 3 个做持续传输复测；
- 自动选择最佳成功项，也可以手动指定；
- 可暂时禁用表现不佳的候选，并在保留历史成绩的同时随时重新启用；
- 真实播放缓冲耗尽时，可尝试切到下一可用候选；
- 自动重新优选有积极、平衡、低频三档，默认使用平衡；
- 动态学习本机近期遇到的可用节点，同时限制数量和有效期。

扩展不会在后台按时钟测速。自动复测只会在播放页可见、视频正在播放、确有媒体 Range 请求且缓冲安全时发生。只开着 B 站首页、动态页、直播页或暂停的视频不会触发它。

关于范围和隐私：

- 仅支持 B 站视频、番剧与课程点播页；
- 仅观察和切换 `*.bilivideo.com` 媒体请求；
- 不处理直播，不修改其他网站的请求；
- 不申请全局代理、Cookie、历史记录或 `<all_urls>` 权限；
- 设置、学习记录和测速摘要只保存在本机；
- 不含广告、分析 SDK、遥测或远程代码；
- 不存在开发者控制的中转服务器。

这不是 VPN，也不能绕过地区版权、登录或失效签名。测速结果只代表当前视频和当前网络路径；如果所有候选的持续带宽都不够，降低清晰度通常更有效。

本扩展为非官方开源项目，与哔哩哔哩不存在隶属、授权或背书关系。
