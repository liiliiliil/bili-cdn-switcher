# v1.7.0 发布检查清单

## 代码与版本

- [ ] `manifest.json` 的 `version` 为 `1.7.0`
- [ ] `package.json` 的版本与 Manifest 一致
- [ ] `CHANGELOG.md` 已有 v1.7.0 条目
- [ ] `npm run check` 通过
- [ ] `git diff --check` 通过
- [ ] CI 在支持的 Node 版本上通过
- [ ] 包内没有远程代码、遥测、广告或开发者服务器地址

## 权限与隐私

- [ ] 逐项核对 `activeTab`、`storage`、`webRequest`、`declarativeNetRequestWithHostAccess`
- [ ] host 权限仍只包含 `www.bilibili.com`、`m.bilibili.com` 与 `*.bilivideo.com`
- [ ] 用全新 Chrome 配置安装一次，记录真实安装权限提示
- [ ] README、弹窗、商店文案和 `PRIVACY.md` 的范围一致
- [ ] 隐私政策 URL 在 GitHub 主分支公开可访问
- [ ] 数据使用字段按保守口径披露本地处理的浏览活动与网站资源

## 图片与文案

- [ ] 包内有 128×128 PNG 图标，主体周围保留合适透明边距
- [ ] 16/32/48px 工具栏图标在浅色、深色背景下都能看清
- [ ] 至少上传一张 1280×800 截图
- [ ] 上传 440×280 小型宣传图
- [ ] 截图不含真实视频、账号、签名 URL 或可反查的测试信息
- [ ] 商店名称、短说明、详细说明和单一用途互相一致
- [ ] 没有暗示官方授权、合作或背书

## 手动回归

- [ ] 从全新解压目录加载，扩展详情显示 v1.7.0
- [ ] 开关、自动/手动模式和三档复测设置均可用
- [ ] 修改复测档位后，完整重载扩展仍能保留
- [ ] 自动模式能捕获当前 host、完成两阶段测速并建立会话规则
- [ ] 随机拖动进度条后能继续播放且规则仍有效
- [ ] 停用扩展后规则被移除或不再生效
- [ ] B 站首页、动态页、直播页和非 B 站页面不触发测速
- [ ] 浏览器控制台没有来自扩展源码的未处理错误

## 打包

- [ ] 运行 `npm run package`
- [ ] ZIP 根目录直接包含 `manifest.json`
- [ ] ZIP 只包含运行所需文件、LICENSE、README 与隐私说明
- [ ] 商店截图、测试报告、源码备选图标和开发配置不放入运行包
- [ ] 解压 ZIP 后再次运行 `npm run check` 或等价静态检查
- [ ] 记录 ZIP 文件名、大小和 SHA-256

## 提交

- [ ] 开发者账号已启用两步验证
- [ ] 联系邮箱可正常收信
- [ ] 选择延迟发布，审核通过后先做最后一次检查
- [ ] 没有在未确认开发者协议、费用或发布范围时直接提交
- [ ] 合并发布 PR 后再创建 `v1.7.0` 标签与 GitHub Release
