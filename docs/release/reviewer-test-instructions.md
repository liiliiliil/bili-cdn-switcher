# Chrome Web Store 审核测试说明

## 是否需要账号

不需要扩展自己的账号。审核人员可使用任意能够正常播放公开 B 站点播视频的浏览器环境。

## 建议步骤

1. 安装扩展并固定到工具栏。
2. 打开任意公开的 `https://www.bilibili.com/video/...` 点播页并开始播放。
3. 点击扩展图标，确认右上角开关开启。
4. 等待弹窗中的“当前观测”显示一个 `*.bilivideo.com` host。
5. 点击“重新优选”。扩展会先初筛，再对成功候选做持续复测。
6. 保持“自动选择”，或切到“手动选择”并点一个成功候选。
7. 观察“重定向到”是否更新。刷新页面或拖动进度条后，后续媒体请求应继续使用当前规则。
8. 对任一非原始候选点击“禁用”，确认它保留历史成绩但不再参与选择；点击“重新启用”可恢复参选。
9. 关闭开关，确认“重定向到”变为未启用；扩展不再为该标签页保留有效替换规则。

## 预期边界

- B 站首页、动态页与直播页不会运行点播内容脚本，也不会触发测速。
- 其他网站不会出现扩展状态，也不会被修改请求。
- 某些候选可能因跨域、签名或网络路径原因测速失败；失败项不会被自动选择。
- 测速会额外读取当前视频的 Range 数据，每轮理论上限约 4 MB。

## 不需要提供

- 登录凭据
- 付费内容
- 专用测试账号
- 特定视频 ID
- 开发者服务器

如果审核环境无法访问 B 站媒体 CDN，扩展应显示尚未捕获或测速失败，而不是访问其他域名作为替代。
