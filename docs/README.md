## 公开信息边界

公开文档不得包含：

- 测试视频 ID、标题、UP 主或个人空间；
- 账号标识、精确播放量或可反查来源页面；
- 完整媒体 URL、签名参数、Cookie 或认证信息；
- 不必要的精确位置或其他个人信息。

测试样本应使用匿名代号，只保留解释扩展行为所需的聚合技术数据。
