# Assets

- `icons/`：扩展实际使用的 PNG 图标。128px 版本遵循商店透明边距建议；16/32/48px 版本从同一源图居中裁切，避免工具栏主体过小。
- `brand/icon-source.svg`：当前原创矢量图标源文件。
- `brand/icon-imagegen-{16,32,128}.png`：图像生成能力制作的缩小备选，只用于比较，默认不进入 Manifest 或发布 ZIP。原始大图不进仓库，避免为了一个备选图标增加近 2 MB。
- `store/`：Chrome Web Store 上传图片。
- `store/source/`：可编辑 SVG 源文件。为兼容 macOS Quick Look 渲染，使用方形画布；导出后裁取中央的目标尺寸。

图标概念是“一排候选节点中自动选中一个”：五枚圆润的无孔 B 以尺寸和颜色表达远近，粉色表示当前选择。图形为原创轮廓，没有使用哔哩哔哩的图形标识。商店截图中的 host 均为匿名占位名。
